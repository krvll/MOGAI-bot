# MOGAI - ИИ-помощник по охране труда и технике безопасности

Направление 5.1.2 «AIChatBots». Telegram-бот: @MOG_AI_agent_Bot

## Проблема
Инструкции по охране труда — это десятки страниц, которые работники часто не читают.
Инструктажи проводятся формально, знания не проверяются, а в нужный момент ответа под рукой нет.
Нарушения техники безопасности — одна из причин производственного травматизма.
Именно эту проблему Положение чемпионата называет в задачах: «производство, экология и безопасность труда».

## Решение
MOGAI — помощник в кармане у каждого рабочего, мастера и студента на практике:
- ❓ **Вопрос — ответ со ссылкой на пункт инструкции.** Пример: «Можно ли работать на сверлильном станке в перчатках?»
- 🎤 **Голосовые вопросы** — можно спросить, не снимая перчаток.
- 🦺 **Проверка фото рабочего места** — ИИ находит нарушения: нет каски, загромождённый проход, провод на полу и т.п.
- 📝 **Тест после инструктажа** — викторина в Telegram, подсчёт баллов, зачёт от 80%.
- 📚 **Готовая база инструкций** — бот работает сразу, без загрузки файлов.
- 📎 **Свои документы** — можно прислать инструкции предприятия: PDF (и сканы), Word, Excel, PowerPoint, фото.
- 🌐 Казахский, русский, английский. Бот помнит контекст диалога.

## Сфера применения
- Производственные предприятия, стройки, мастерские
- Колледжи: инструктаж студентов перед практикой и работой в мастерских
- Специалисты по охране труда: быстрая проверка знаний персонала

## Технологии
- Python, python-telegram-bot
- ChatGPT (OpenAI API), модель `gpt-4.1-mini`: ответы, анализ фото (компьютерное зрение), генерация тестов (структурированный вывод JSON)
- Whisper (OpenAI): распознавание речи
- pypdf, pypdfium2, python-docx, openpyxl, python-pptx, Pillow: чтение документов

## База знаний
Папка `knowledge/` содержит 7 **учебных** инструкций: общие требования, СИЗ, работы на высоте,
электробезопасность, сварка, пожарная безопасность, первая помощь.
Чтобы бот отвечал по официальным документам, положите в эту папку инструкции вашего предприятия
или колледжа (PDF, DOCX, TXT, MD) и перезапустите бота.

## Запуск (Windows)
1. Установите Python 3.10+ с https://www.python.org/downloads/ и отметьте **Add Python to PATH**.
2. Скопируйте `.env.example` в `.env` и впишите `OPENAI_API_KEY` и `TELEGRAM_BOT_TOKEN`.
3. Дважды кликните `start.bat`. При первом запуске он сам установит библиотеки.

## Структура
| Файл | Назначение |
|---|---|
| `telegram_bot.py` | бот: меню, вопросы, голос, фото, тесты |
| `core.py` | ИИ: чтение файлов, база знаний, ответы, распознавание речи, генерация тестов |
| `knowledge/` | база инструкций по охране труда |
| `start.bat` | установка и запуск в один клик |
